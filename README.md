# 가계부 저축 트래커

카테고리별 소비 상한과 12개월 저축 목표(월 50만원, 총 600만원)를 관리하는 개인용 웹앱입니다.
서버 없이 GitHub Pages로 호스팅하고, 폰에서 "홈 화면에 추가"하면 앱처럼 아이콘이 생기고 오프라인에서도 열립니다.

## 배포 방법 (5분)

1. GitHub에서 새 저장소(repository)를 만듭니다. (예: `budget-tracker`, Public으로 설정)
2. 이 폴더 안의 파일들(`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, `icons/` 폴더)을
   그 저장소에 그대로 업로드합니다.
   - GitHub 웹사이트에서 "Add file → Upload files"로 드래그해서 올려도 됩니다. Git을 몰라도 됩니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. "Branch" 항목에서 `main`(또는 `master`)과 `/ (root)`를 선택하고 저장합니다.
5. 1~2분 기다리면 `https://<your-github-id>.github.io/budget-tracker/` 같은 주소가 생깁니다.

## 폰에서 앱처럼 쓰기

- **아이폰(Safari)**: 위 주소로 접속 → 공유 버튼 → "홈 화면에 추가"
- **안드로이드(Chrome)**: 위 주소로 접속 → 메뉴(⋮) → "홈 화면에 추가" 또는 자동으로 뜨는 설치 배너 사용

홈 화면에 아이콘이 생기고, 탭하면 브라우저 주소창 없이 전체 화면 앱처럼 열립니다.

## 데이터에 대해 꼭 알아두실 점

- 모든 데이터는 **이 기기의 이 브라우저 안에만** 저장됩니다(서버 없음).
- 폰을 바꾸거나, 브라우저 데이터를 지우거나, 앱을 삭제하면 데이터가 사라질 수 있습니다.
- **설정 탭 → 데이터 백업 → 내보내기**로 주기적으로 JSON 파일을 저장해두세요.
- 다른 기기로 옮기려면: 내보내기한 파일을 그 기기로 옮긴 뒤 같은 페이지에서 **가져오기**를 누르면 됩니다.

## 나중에 기능을 더 넣고 싶다면

- 클라우드 동기화(여러 기기에서 실시간 공유)를 원하시면, Firebase나 Supabase 같은 무료 백엔드를 붙이는 것도 가능합니다. 지금 버전은 그 전 단계(로컬 저장 전용)입니다.
- 카테고리를 더 추가하거나 상한을 바꾸고 싶으면 앱의 "설정" 탭에서 바로 수정하면 됩니다. 코드를 다시 건드릴 필요 없습니다.
